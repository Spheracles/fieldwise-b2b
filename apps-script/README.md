# 預約初談接收程式（Google Apps Script）

網站的預約初談表單把資料以 JSON 送到這支程式，程式寫入試算表「預約初談」工作表，並寄 Email 通知試算表擁有者。

## 部署

1. 建立一份 Google 試算表，例如「田序共創 B2B 預約初談」。
2. 試算表選單：擴充功能 → Apps Script，把 `Code.gs` 的內容整份貼上並儲存。
3. 上方函式選 `setup` → 執行，依畫面授權（會建立「預約初談」工作表）。
4. 部署 → 新增部署作業 → 類型選「網頁應用程式」
   - 執行身分：我
   - 誰可以存取：所有人
5. 複製網頁應用程式網址（結尾是 `/exec`），填到 `site/js/data.js` 的 `SITE.inquiry.endpoint`，並把 `enabled` 改成 `true`，再執行 `node site/build.mjs`。

## 修改程式後

部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署。這樣網址不變，網站不用改。

## 欄位

試算表欄位由 `COLUMNS` 決定，代碼要和 `site/js/data.js` 的 `INQUIRY` 題目 `key` 一致。新增欄位只能加在最後面。最後一欄「處理狀態」預設「未處理」，給團隊追蹤用。

## 安全

- 防機器人欄位有值時不寫入。
- 稱呼、Email、身分、個資同意時間為必填，Email 會檢查格式。
- 以 `= + - @` 開頭的內容會加上單引號，避免被試算表當成公式執行。
